# System Log Analyzer

A Core Java console-based application designed to read, analyze, and search system/application log files.

## 🚀 Features

- Load log files from the local system
- Analyze INFO, WARN, and ERROR log entries
- Display log statistics
- Search logs using keywords
- Simple interactive console menu
- Handles file and input-related exceptions

## 🛠️ Technologies

- Java
- OOP
- Collections Framework
- File Handling
- Exception Handling
- Java Console / Scanner
